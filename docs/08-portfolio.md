# 08. 포트폴리오 설명

## 한 줄 소개

Unity 기반 산업용 키오스크 시스템을 설계하고 주문, 상태, 알람, 로그 기능과 파일 기반 데이터 영속성 및 영수증 이미지 출력을 구현했습니다.

## 담당 내용

- 전체 UI 구조 설계
- Home / Detail 페이지 전환
- Order CRUD 기능
- 입력 검증 및 주문번호 자동 생성
- TXT 기반 주문 저장
- JSON 기반 로그 저장
- CSV 로그 Export
- Receipt PNG 캡처
- Dashboard 실시간 요약
- 반복 UI Prefab화
- 로그 경량화 및 최종 빌드 테스트

## 문제 해결 사례

### 1. UI와 데이터 로직 혼합

초기에는 Order 페이지가 UI Row와 데이터를 직접 함께 관리했습니다. 이후 `scr_OrderController`를 도입해 데이터 저장과 UI 표시 책임을 분리했습니다.

### 2. 로그 누적에 따른 성능 부담

페이지 이동과 단순 클릭까지 기록되면서 의미 없는 로그가 증가했습니다. 실제 데이터 변화만 기록하도록 정책을 변경하고 화면 및 파일 저장 개수를 제한했습니다.

### 3. 영수증 PNG 저장

주문 데이터를 영수증 UI에 반영한 후 `WaitForEndOfFrame`, `ReadPixels`, `EncodeToPNG` 흐름으로 저장했습니다. 저장 후 Texture를 해제하여 메모리 누적을 방지했습니다.

### 4. 빌드 컴파일 오류

Editor에서는 보이지 않던 `System.IO` 네임스페이스 누락이 Windows Build에서 발견되었습니다. `using System.IO;`를 추가해 `File`, `Path`, `Directory` 오류를 해결하고 최종 빌드에 성공했습니다.

## 면접 설명 예시

이 프로젝트는 단순한 UI 시안이 아니라 실제로 데이터를 저장하고 다시 불러오는 산업용 키오스크 흐름을 구현한 프로젝트입니다. 주문 관리, 상태 변경, 알람, 시스템 로그를 하나의 화면에 통합했고, UI와 데이터 저장 책임을 분리했습니다. 또한 로그가 무한히 증가하지 않도록 의미 있는 변화만 기록하고 저장 개수를 제한하여 일반 PC에서도 안정적으로 동작하도록 최적화했습니다.
