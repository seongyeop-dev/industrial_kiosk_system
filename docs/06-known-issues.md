# 06. Known Issues

현재 확인된 주요 기능 오류는 없으며, 아래 항목은 구현 범위와 향후 확장 시 고려할 내용입니다.

## 테스트 알람 방식

알람 화면은 외부 PLC, 설비 또는 센서에서 데이터를 수신하지 않습니다. `scr_AlarmController`의 테스트 알람 생성 기능으로 목록·상세 조회와 화면 연동을 확인했습니다.

**개선 방향**

- 설비 API, Socket 또는 산업용 통신 모듈 연동
- 알람 코드와 설비 ID 기반 데이터 모델 확장
- 발생·확인·해제 상태 분리

## 로컬 파일 기반 저장

주문과 로그는 `Application.persistentDataPath` 아래의 로컬 파일에 저장합니다. 여러 단말 간 데이터 공유, 서버 백업과 사용자 권한 관리는 포함하지 않습니다.

**개선 방향**

- Backend API 또는 데이터베이스 연동
- 저장 실패와 재시도 상태 표시
- 사용자 계정과 권한별 기능 분리

## 로그 보관 범위

화면에는 최근 15건, 메모리와 JSON 파일에는 최근 30건을 유지합니다. 포트폴리오 규모에서 UI 누적을 제한하기 위한 정책이며 장기 이력 보관 용도는 아닙니다.

**개선 방향**

- 날짜별 로그 파일 분리
- Pagination 또는 Virtualized List 적용
- 장기 이력 검색과 Archive 기능 추가

## 성능 검증 범위

대량 주문, 수천 건 이상의 로그와 장시간 무중단 실행 환경은 테스트하지 않았습니다. 현재 파일 저장과 PNG 인코딩은 Unity 메인 흐름에서 처리합니다.

**개선 방향**

- 대량 데이터 기준 Profiling
- 파일 직렬화와 저장 비동기 처리 검토
- 저장 진행·완료·실패 상태 UI 추가
