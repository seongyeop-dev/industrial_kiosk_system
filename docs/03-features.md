# 03. 기능 설명

## Home

- 주요 기능 바로가기
- 총 주문 수, 실행 중 주문 수, 완료 수 표시
- 시스템 상태 표시
- 최근 로그, 최근 알람, 마지막 동작 표시
- 현재 날짜와 시간 표시

## Dashboard

- 전체 주문 수
- Ready / Running / Error 상태별 수량
- 현재 시스템 상태
- 마지막 동작
- 최근 로그
- 최근 알람
- 현재 시간
- Order / Status / Alarm / System Log 바로가기

## Order

- 주문 추가
- 주문 수정
- 선택 주문 삭제
- 마지막 주문 삭제
- 선택 해제
- 오늘 날짜 자동 입력
- 주문번호 자동 생성
- 주문번호 중복 방지
- 제품명 / 수량 / 날짜 입력 검증
- 저장 후 Master TXT 및 주문서 TXT 생성
- 저장 또는 수정 시 영수증 PNG 생성

## Status

- READY / RUNNING / ERROR 상태 변경
- Status 페이지와 BottomBar 상태 동시 갱신
- 최근 상태 변경 Preview 표시
- Dashboard / Home 연동
- 상태 변경 로그 기록

## Alarm

- 더미 알람 생성
- 알람 목록 표시
- 알람 선택 및 상세 확인
- 전체 알람 삭제
- Dashboard 및 Home 최근 알람 연동

## System Log

- Order / Status / Alarm 중심 로그 기록
- 단순 페이지 이동 및 클릭 로그 제외
- 최신 로그 우선 표시
- 카테고리 필터
- Summary / Detail 표시
- JSON 저장
- CSV Export
- 화면 표시 및 저장 개수 제한
